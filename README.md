# Credit-Card-Dashboard
**Project Title:** Credit card Dashboard and Customer details dashboard
**About The Dashboard:** This dashboard presents a comprehensive analysis of a credit card company’s transactions, highlighting customer spending patterns based on card type and category. It also provides insights into customer demographics, including education, occupation, and background, along with the revenue generated for the company.

Tech Stack Used:
~ MS Excel — Used for data cleaning, filtering, and initial preprocessing
~ PostgreSQL — Used for database management and data storage
~ Power BI — Primary platform used for data visualization and dashboard creation
~ DAX (Data Analysis Expressions) — Used to create calculated measures, dynamic insights, and conditional logic
